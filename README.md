## ✨ 应用简介

**字知**是一款专注于汉字笔画学习的 Android 应用，特别针对中老年用户的使用习惯进行了优化设计。通过在屏幕上跟随标准笔画描写汉字，帮助用户掌握正确的汉字书写顺序，在轻松愉悦的练习中提升书写能力。

应用采用了**大字体、高对比度**的视觉设计，界面简洁明了，操作直观易懂，即使是不太熟悉智能手机的用户也能快速上手。

---

## 🎯 核心功能

### 📝 笔画描写练习
- **跟随笔画书写** — 在屏幕上按照标准笔顺逐笔描写汉字，系统会实时判断书写是否正确
- **笔画提示** — 遇到不熟悉的笔画时，可以查看提示引导，帮助完成书写
- **即时反馈** — 每一笔写完后立即给出视觉反馈，写对了会有鼓励效果

### 🔄 智能复习
- **练习模式** — 学习新字，逐步扩大识字量
- **复习模式** — 巩固已学汉字，加深记忆
- **学习进度追踪** — 自动记录每个字的学习和复习状态

### 🔊 语音朗读
- **自动发音** — 进入练习时自动朗读当前汉字及其对应词语
- **手动播放** — 随时点击喇叭图标再次聆听发音
- **系统语音** — 使用设备自带的中文语音引擎，无需额外下载

### ⚙️ 管理与设置
- **总览面板** — 查看整体学习进度和统计数据
- **字库管理** — 管理应用中的汉字，支持启用或禁用特定汉字
- **学习数据** — 查看详细的学习记录和数据
- **数据备份** — 支持导出和导入学习数据，更换设备也不丢失进度
- **个性化设置** — 根据个人偏好调整应用行为

## 📲 安装方式

1. 下载 APK 安装包
2. 在 Android 设备上打开安装包
3. 如有安全提示，选择"允许安装"
4. 安装完成后，在桌面找到"字知"图标即可开始使用

> **系统要求**：Android 11 (API 30) 及以上版本

---

## 📖 使用指南

### 快速开始

1. **打开应用** — 点击桌面上的"字知"图标
2. **选择模式** — 在主页选择「练习」学习新字，或选择「复习」巩固已学内容
3. **开始书写** — 在描写区域跟随提示笔画进行书写
4. **完成练习** — 写完所有笔画后自动进入下一个字
5. **管理界面** — 长按首页右上角的设置图标进入管理界面
